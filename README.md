# 대전 타슈 자전거 쏠림 지도

`index.html` 파일을 브라우저로 열면 웹사이트를 볼 수 있습니다.

## 파일 설명

- `index.html`: 웹페이지 본문
- `styles.css`: 디자인
- `app.js`: 지도 표시와 필터 기능
- `data/stations.js`: 웹에서 바로 읽는 대여소별 요약 데이터
- `data/stations.json`: 같은 요약 데이터를 JSON 형태로 저장한 파일
- `scripts/build-data.ps1`: 대여이력 CSV를 다시 분석할 때 쓰는 스크립트

## 데이터 기준

쏠림 점수는 아래 방식으로 계산했습니다.

```text
쏠림 점수 = 반납 횟수 - 대여 횟수
```

- 빨간색: 대여가 반납보다 많아서 자전거가 부족해지는 대여소
- 초록색: 반납이 대여보다 많아서 자전거가 쌓이는 대여소
- 회색: 대여와 반납이 비슷한 대여소

현재 데이터는 `2026년 2월` 대여이력 파일 기준입니다.
